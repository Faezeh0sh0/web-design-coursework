هدف پروژه

هدف این پروژه آشنایی با نحوه ساختاربندی محتوای متنی طولانی در HTML و استفاده صحیح از تگ‌های معنایی است.

شرح تمرین

یک صفحه وبلاگی با استفاده از HTML طراحی کنید که شامل عنوان، محتوای مقاله، تیترهای فرعی، فهرست و نقل‌قول باشد. از تگ‌های معنایی مناسب برای ساختاربندی محتوا استفاده کنید. همچنین یک تصویر به همراه توضیحات و چند پیوند مرتبط در صفحه قرار دهید. هدف این تمرین، آشنایی با ساختار صحیح و معنایی صفحات وب است.

الزامات پروژه
1. ساختار صفحه: استفاده از تگ‌های header، main، article و footer.
2. عنوان‌ها: استفاده از یک h1 برای عنوان اصلی و h2 و h3 برای بخش‌های داخلی.
3. محتوای متنی: استفاده از p، ul، ol، blockquote، cite، code و pre متناسب با محتوا.
4. تأکید متنی: استفاده صحیح از strong و em.
5. پیوندها: استفاده از متن توصیفی برای تمام لینک‌ها.
6. تصویر: قرار دادن حداقل یک تصویر در figure همراه با figcaption و ویژگی alt.
7. اطلاعات صفحه: تعریف title، charset، viewport و description در بخش head.
