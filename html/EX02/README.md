# **پروژه: طراحی فرم تماس (Contact Form)**



مقدماتی

HTML



### **هدف پروژه**

هدف این پروژه آشنایی با ساختار فرم‌ها در HTML، انواع فیلدهای ورودی و نحوه دریافت اطلاعات از کاربران است.

### **شرح تمرین**

یک صفحه شامل فرم تماس طراحی کنید که کاربران بتوانند از طریق آن اطلاعات خود را وارد کرده و پیامشان را ارسال کنند. فرم باید شامل فیلدهایی برای نام و نام خانوادگی، آدرس ایمیل، موضوع و متن پیام باشد. همچنین امکان انتخاب یک گزینه از فهرست و عضویت اختیاری در خبرنامه را فراهم کنید. برای هر فیلد، برچسب مناسبی در نظر بگیرید و از قابلیت‌های اعتبارسنجی HTML برای بررسی ورودی‌ها استفاده کنید.

### **الزامات پروژه**

1. **ساختار فرم:** استفاده از تگ‌های `form`، `fieldset` و `legend` برای سازمان‌دهی فیلدها.
2. **فیلدهای ورودی:** استفاده از `input` با انواع مناسب مانند `text`، `email` و `checkbox`.
3. **متن پیام:** استفاده از `textarea` برای دریافت پیام کاربران.
4. **گزینه‌های انتخابی:** استفاده از `select` و `option` برای ایجاد فهرست انتخابی.
5. **برچسب‌گذاری:** استفاده از `label` برای معرفی هر فیلد ورودی.
6. **اعتبارسنجی:** استفاده از ویژگی‌هایی مانند `required`، `minlength`، `maxlength` و `placeholder` متناسب با هر فیلد.
7. **ارسال فرم:** استفاده از `button` با نوع `submit` برای ارسال اطلاعات.

نکته: تمرکز این تمرین بر HTML است؛ بنابراین نیازی به استفاده از CSS یا JavaScript نیست.
