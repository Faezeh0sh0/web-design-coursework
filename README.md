# Web Design Lab

### مجموعه تمرین‌های درس طراحی وب

این مخزن با هدف تکمیل محتوای آموزشی درس طراحی وب و فراهم کردن بستری برای تمرین عملی مباحث ارائه‌شده در کتاب درسی ایجاد شده است.

تمرین‌های این مجموعه به تفکیک فناوری و فصل‌های کتاب دسته‌بندی شده‌اند تا دانشجویان بتوانند هم‌زمان با مطالعه هر فصل، مفاهیم آن را از طریق حل مسئله و پیاده‌سازی عملی تثبیت کنند.

## Exercise Levels

تمرین‌ها در سه سطح طراحی می‌شوند:

- 🟢 Easy — تثبیت مفاهیم پایه
- 🟡 Intermediate — ترکیب مفاهیم و حل مسائل کاربردی
- 🔴 Challenge — مسائل پیچیده‌تر و نیازمند تفکر مستقل

## How to Use

1. فصل موردنظر را از بخش مربوط به فناوری انتخاب کنید.
2. ابتدا محتوای همان فصل از کتاب درسی را مطالعه کنید.
3. تمرین‌ها را به ترتیب انجام دهید.
4. خروجی خود را با الزامات مسئله مقایسه کنید.
5. در صورت تمایل، چالش پایانی فصل را حل کنید.
