پروژه: طراحی فرم ورود (Login Form)
مقدماتی
 HTML
 CSS

هدف پروژه
هدف این پروژه آشنایی با طراحی فرم‌های ورود کاربران، استفاده از انواع فیلدهای ورودی و استایل‌دهی به عناصر فرم با CSS است.
شرح تمرین
یک صفحه ورود (Login Page) با استفاده از HTML و CSS طراحی کنید. صفحه باید شامل فیلدهای نام کاربری یا ایمیل و رمز عبور باشد و امکان ورود به حساب کاربری را برای کاربران فراهم کند. همچنین گزینه‌هایی مانند به‌خاطر سپردن اطلاعات ورود (Remember Me)، بازیابی رمز عبور و ثبت‌نام کاربر جدید را در نظر بگیرید. ظاهر فرم باید ساده، منظم و کاربرپسند باشد و با استفاده از CSS طراحی شود.
الزامات پروژه
1. ساختار فرم: استفاده از تگ‌های form، label و input.
2. فیلدهای ورودی: استفاده از type="email" یا type="text" برای نام کاربری و type="password" برای رمز عبور.
3. گزینه‌های فرم: استفاده از checkbox برای قابلیت Remember Me.
4. اعتبارسنجی: استفاده از ویژگی‌هایی مانند required و placeholder.
5. دکمه ورود: ایجاد دکمه ارسال فرم با استفاده از button.
6. استایل‌دهی: استفاده از CSS برای تنظیم رنگ‌ها، فونت، فاصله‌گذاری، حاشیه‌ها و پس‌زمینه فرم.
7. تعامل بصری: تعریف حالت‌های hover و focus برای فیلدها و دکمه‌ها.
