پروژه: طراحی کارت‌های قیمت‌گذاری (Pricing Cards)
مقدماتی
 HTML
 CSS

هدف پروژه
هدف این پروژه آشنایی با CSS Box Model، نحوه چیدمان عناصر با Flexbox و طراحی کامپوننت‌های قابل استفاده مجدد در صفحات وب است.
شرح تمرین
یک ردیف شامل سه کارت قیمت‌گذاری با استفاده از HTML و CSS طراحی کنید. هر کارت باید نمایانگر یک پلن اشتراک متفاوت باشد و شامل نام پلن، قیمت، توضیح کوتاه، فهرست امکانات و دکمه انتخاب پلن باشد. کارت میانی باید به‌عنوان پلن پیشنهادی، از نظر اندازه و ظاهر نسبت به دو کارت دیگر متمایز باشد. طراحی باید به‌گونه‌ای باشد که هر سه کارت ارتفاع یکسانی داشته باشند و دکمه‌های آن‌ها در یک راستا قرار بگیرند.
الزامات پروژه
1. ساختار کارت‌ها: ایجاد سه کارت مستقل با استفاده از عناصر مناسب HTML.
2. چیدمان: استفاده از Flexbox برای قرارگیری کارت‌ها در کنار یکدیگر.
3. Box Model: استفاده صحیح از padding، gap، border و box-sizing.
4. تأکید بصری: متمایز کردن کارت میانی به‌عنوان پلن پیشنهادی.
5. تایپوگرافی: ایجاد سلسله‌مراتب بصری مناسب برای قیمت، نام پلن و امکانات.
6. تعامل‌پذیری: تعریف حالت‌های hover و focus برای دکمه‌های انتخاب پلن.
7. یکپارچگی طراحی: حفظ ارتفاع یکسان کارت‌ها و قرارگیری دکمه‌ها در انتهای آن‌ها.
