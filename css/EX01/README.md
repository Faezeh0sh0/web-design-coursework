پروژه: طراحی وب‌سایت رزومه شخصی (Personal Portfolio Website)
مقدماتی
 HTML
 CSS

هدف پروژه
هدف این پروژه آشنایی با اصول استایل‌دهی صفحات وب با CSS، طراحی چیدمان واکنش‌گرا (Responsive) و ایجاد یک وب‌سایت شخصی برای معرفی مهارت‌ها و سوابق فردی است.
شرح تمرین
ساختار HTML وب‌سایت شخصی خود را که در تمرین قبلی ایجاد کرده‌اید، با استفاده از CSS به یک وب‌سایت رزومه شخصی تبدیل کنید. وب‌سایت باید شامل بخش‌هایی برای معرفی، مهارت‌ها، سوابق تحصیلی و کاری، پروژه‌ها و اطلاعات تماس باشد. طراحی صفحه باید در اندازه‌های مختلف نمایشگر، از جمله موبایل و دسکتاپ، به‌درستی نمایش داده شود. در این تمرین تمرکز بر طراحی چیدمان، انتخاب رنگ و فونت مناسب و ایجاد تجربه کاربری مطلوب است.
الزامات پروژه
1. ساختار و چیدمان: حفظ ساختار HTML تمرین قبلی و استایل‌دهی بخش‌های مختلف صفحه.
2. رنگ‌بندی: انتخاب و استفاده یکپارچه از پالت رنگی مناسب.
3. تایپوگرافی: انتخاب فونت مناسب و تنظیم اندازه، وزن و فاصله متون.
4. چیدمان عناصر: استفاده از CSS Box Model و تکنیک‌هایی مانند Flexbox.
5. طراحی واکنش‌گرا: استفاده از Media Queries برای سازگاری با اندازه‌های مختلف نمایشگر.
6. نوار پیمایش: طراحی و استایل‌دهی Navigation Bar به‌صورت واکنش‌گرا.
7. فرم تماس: استایل‌دهی فرم تماس ایجادشده در تمرین قبلی.
