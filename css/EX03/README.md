پروژه: طراحی گالری تصاویر شبکه‌ای (Image Grid)
مقدماتی
 HTML
 CSS

هدف پروژه
هدف این پروژه آشنایی با قابلیت CSS Grid و نحوه ایجاد چیدمان‌های شبکه‌ای، منظم و واکنش‌گرا در صفحات وب است.
شرح تمرین
یک گالری تصاویر با استفاده از HTML و CSS طراحی کنید که شامل شش تصویر در یک چیدمان شبکه‌ای باشد. تصاویر باید مطابق طرح نمونه در اندازه‌ها و موقعیت‌های متفاوت قرار بگیرند. چیدمان گالری باید در اندازه‌های مختلف نمایشگر، از جمله موبایل و دسکتاپ، به‌درستی تغییر کند. می‌توانید از تصاویر پیشنهادی پروژه یا تصاویر دلخواه خود استفاده کنید.
الزامات پروژه
1. ساختار گالری: ایجاد یک ساختار مناسب HTML برای نمایش مجموعه تصاویر.
2. چیدمان شبکه‌ای: استفاده از display: grid برای ایجاد ساختار اصلی گالری.
3. تعریف ستون‌ها و ردیف‌ها: استفاده از ویژگی‌های grid-template-columns و grid-template-rows.
4. موقعیت‌دهی تصاویر: استفاده از ویژگی‌هایی مانند grid-column و grid-row برای تنظیم موقعیت و اندازه تصاویر.
5. فاصله‌گذاری: استفاده از gap برای ایجاد فاصله منظم بین تصاویر.
6. مدیریت تصاویر: استفاده از object-fit برای نمایش مناسب تصاویر در ابعاد مختلف.
7. طراحی واکنش‌گرا: استفاده از Media Queries برای سازگاری گالری با اندازه‌های مختلف نمایشگر.
